# voice_to_voice_gpt

This repository contains a Python application for voice-to-voice interaction using GPT technology. The application likely processes voice input, interacts with a GPT model, and produces voice output.

## Features

- Voice input processing
- GPT-based natural language understanding and response generation
- Voice output synthesis

## Requirements

- Python 3.x
- Dependencies listed in `requirements.txt`

## Installation

1. Clone the repository:

   ```powershell
   git clone https://github.com/RazMuhammad/voice_to_voice_gpt.git; cd voice_to_voice_gpt
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

## Usage

Run the main application:

```powershell
python voiceTOvoiceapp.py
```
